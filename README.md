# 1c-elsi-invoice-upd-automation

Проект предназначен для автоматизации ежемесячного формирования счетов на оплату и УПД в 1С:Бухгалтерия для ООО «ЭЛСИ». Точная архитектура и способ интеграции с 1С пока не утверждены.

## Структура

- `src/` — исходный код.
- `tests/` — тесты на вымышленных данных.
- `DEV/tasks/` — утверждённые задания.
- `DEV/reports/` — отчёты о выполнении.
- `DEV/docs/` — требования, архитектура и безопасность.

Перед работой прочитайте `AGENTS.md` и соответствующее задание в `DEV/tasks/`. Выполняйте только его область изменений и документируйте результат в `DEV/reports/`.

**Конфиденциальность:** не добавляйте реальные бухгалтерские документы, данные контрагентов и сотрудников, реквизиты, выгрузки 1С, секреты или локальные конфигурации. Для разработки используйте только вымышленные данные. Перед каждым коммитом отдельно проверяйте содержимое файлов; `.gitignore` сам по себе не является защитой.
